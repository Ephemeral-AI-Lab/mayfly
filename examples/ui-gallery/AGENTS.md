# `@mayfly-example/ui-gallery`

Injects `mayflyPanes` and publishes a static right-lane gallery with bottom
fallback, plus one view of status row 2 (`src/groups/views.ts`) and a bottom prompt pane
(`src/groups/prompt.ts`) whose host answers the prompt's events. Use only
public wire nodes; keep Markdown, Mermaid, and all chart variants represented
without renderer-specific options.
