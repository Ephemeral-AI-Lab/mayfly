# `@mayfly-example/overlay`

Injects native `commands`/`settings` and `mayflyOverlays`. The command opens a
persistent two-page settings form; repeated entry focuses the existing overlay.
Frontend owns drafts, pages, selection, submission locks, and dirty dismissal.

Publish body content only. Native descriptor revisions accompany path writes
and structured replies; both resolved-value and raw-document events refresh
snapshots. Never echo edits with `set()` or keep a plugin-owned form/tab machine.
Fiber unload removes the namespace, command, observers, and overlay.
