# `@mayfly-example/overlay`

Ordinary Cordis plugin injecting native `commands`, `settings`, and direct
`mayflyOverlays`. Its command opens a persistent two-page settings form; repeated
entry focuses the existing registration. The frontend owns drafts, page state,
selection, submission locking, and dirty-dismissal confirmation.

The request contributes body content only. Core owns frame, focus, size, and
width. Native descriptor revisions accompany path writes and structured replies;
both resolved-value and raw-document events refresh authoritative snapshots.
Never echo edits with `set()` or retain a plugin-owned form/tab state machine.
Fiber unload removes the namespace, command, observers, and overlay. Keep it
opt-in and do not add gesture tokens or a host facade.
